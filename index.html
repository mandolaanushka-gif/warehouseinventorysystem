About WIMS

Warehouse Inventory Management System

WIMS is a C++ based Warehouse Inventory Management System designed to manage products, monitor stock, process orders and maintain transaction records. It uses Object-Oriented Programming and Data Structures to organize warehouse operations.


Core Concepts: Classes, Encapsulation, Linked Lists, AVL Tree and Queue.

Backend: C++ with a Winsock web server.
